## Проверенные сценарии

- Навигация, начальная сессия без даты/Zoom, интерактивное объяснение DNS.
- Создание, редактирование, сортировка/фильтры, заметки, persistence, отмена и подтверждение удаления встречи.
- Настроенная Zoom-ссылка открывает новую вкладку: внешняя тестовая страница подменена локальным ответом, реальный Zoom не вызывался.
- Проверка timezone, Escape и возврат фокуса из диалога.
- Изменение статуса темы, сохранение после reload, вложенные темы, раскрытие/сворачивание, переименование и удаление поддерева.
- Профиль, полезные ссылки и создание/изменение/удаление проектов.
- Терминал: help, история и восстановление черновика, echo как текст, неизвестные команды, clear, завершение и остановка pipeline.
- JSON download, импорт после подтверждения, отмена импорта, отказ некорректному backup без изменения данных, reset.
- Повреждённый LocalStorage не перезаписывается до подтверждённого восстановления.
- Ошибка записи оставляет изменения в памяти и позволяет скачать JSON.
- Мобильная форма, Tab/Shift+Tab внутри dialog, создание ID при отсутствии `crypto.randomUUID`.
- Reduced-motion завершает pipeline сразу; меню работает в свёрнутом виде.

В сборке остаются два информационных предупреждения Rollup о комментариях `@__PURE__` внутри Zod: комментарии удаляются сборщиком, build завершается успешно. Предупреждение npm 11 о неразрешённом postinstall esbuild не помешало сборке с установленным платформенным бинарным пакетом; на данной машине выполнение дополнительного install-script не потребовалось.
