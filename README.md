# MiT-viis-2026

**DevOps Mentorship Playground** — небольшое личное пространство для знакомства ментора и менти: от первых архитектурных схем до собственного приложения на VPS.

Русский интерфейс, тёмный спокойный стиль, рабочие редакторы и безопасный учебный терминал. Первая встреча посвящена знакомству, ожиданиям и проектам. Это статический single-user-first прототип; сервер и регистрация не нужны.

## Что работает

- **Главная** — следующая встреча, краткая повестка, прогресс и быстрые переходы.
- **Встречи** — хронологический список, создание/редактирование/удаление с подтверждением, дата, время, длительность, IANA timezone, статусы, Zoom URL и заметки. Есть фильтры будущих, прошедших и несогласованных встреч.
- **Программа** — 7 разделов, 36 начальных тем; вложенное дерево, раскрытие, описания, добавление разделов/подтем, редактирование, удаление и три статуса.
- **Терминал** — 15 локальных команд, история ↑/↓, дополнение уникальной команды через Tab, очистка, кофе и учебный deployment pipeline.
- **О менторе** — редактор знакомства, опыта, стека, полезных ссылок и нескольких проектов.
- **Настройки** — timezone по умолчанию, JSON export/import с проверкой и подтверждением, сброс примеров.
- **Как всё связано?** — интерактивные объяснения браузера, DNS, VPS, приложения и базы данных.

## Стек и требования

React 19, TypeScript, Vite 7, Tailwind CSS 4, Lucide, Zod, Luxon. Для проверок: ESLint, Vitest, Playwright, Prettier. Нужны Node.js **22.12+** и npm. Интернет требуется при установке пакетов, но приложение не использует внешние API, CDN, шрифты, аналитику или ключи.

## Установка и запуск

```sh
cd /home/viis/projects/MiT-viis-2026
npm ci
npm run dev
```

Открыть **http://localhost:5174/**. Порт 5174 выбран, чтобы не мешать другому локальному проекту на 5173. `strictPort` не позволяет незаметно переключиться на другой порт. Остановить сервер — Ctrl+C в его терминале.

В текущей рабочей среде глобальный npm отсутствовал. Для неё предусмотрена локальная обёртка (Node + pnpm для первого bootstrap):

```sh
cd /home/viis/projects/MiT-viis-2026
./scripts/npm.sh ci
./scripts/npm.sh run dev
```

Если npm уже установлен, обёртка просто передаёт ему аргументы. Иначе она устанавливает npm в игнорируемую `.tools/`, не меняя систему. Все команды ниже также можно запускать через `./scripts/npm.sh` вместо `npm`.

Dev-сервер доступен по локальной сети благодаря `--host 0.0.0.0`. Для доступа только с этого компьютера: `npm run dev -- --host 127.0.0.1`. Одинаковый URL у двух участников **не создаёт общие данные**.

## Production build

```sh
npm run build
npm run preview -- --port 4174
```

Результат — `dist/`, пригодный для статического хостинга. Маршруты `#/meetings`, `#/roadmap` и другие не требуют server rewrite. Для размещения в подкаталоге настройте `base` в `vite.config.ts`. Публикация и remote Git-репозиторий в эту задачу не входят.

## Подготовка к Session 01

1. Откройте **О менторе → Редактировать профиль**: замените заготовки своим рассказом, опытом, стеком и приветствием. Добавьте 2–3 проекта с коротким объяснением и ссылками.
2. В разделе **Встречи** отредактируйте `Session 01 — Знакомство`: снимите «Дату согласуем позже», задайте согласованные дату/время и Zoom URL. По умолчанию всё это пустое; никаких выдуманных дат и персональных данных нет.
3. Проверьте пояс `Asia/Tbilisi`. Встреча хранит собственный пояс. Настройка общего пояса влияет только на новые встречи.
4. Просмотрите **Программу**: её можно адаптировать прямо на встрече. Выберите тему, измените статус или нажмите «Редактировать тему» / «Добавить подтему».
5. Попробуйте `help`, `coffee`, `git status` и `deploy --dry-run` в терминале.
6. Сохраните **Настройки → Экспорт JSON**. Это ваша копия данных для восстановления или передачи менти.

Для настройки через UI менять файлы не требуется. Чтобы изменить стартовые примеры для **новых** браузеров, редактируйте `src/data/seed.ts`. Существующий LocalStorage не перезаписывается при обновлении seed; применить seed можно только подтверждённым сбросом. Реальные Zoom-ссылки с паролями и личные заметки храните в UI, не коммитьте их в Git.

## Данные и ограничения

Ключ LocalStorage: `mit-viis-2026.workspace.v1`. Сохраняются встречи, программа и статусы, профиль и проекты, настройки. История терминала живёт только пока открыт его раздел. Экспорт содержит весь workspace в JSON с `version: 1`. Импорт **заменяет** данные целиком, не объединяет их; до подтверждения всё остаётся на месте.

LocalStorage относится к конкретному браузеру и origin (протокол + адрес + порт). `localhost:5174`, LAN-адрес и production-сайт — разные хранилища. Нет синхронизации между устройствами, участниками и открытыми вкладками. Редактируйте workspace в одной вкладке; иначе последнее сохранение может затереть изменения другой вкладки. Для переноса используйте JSON. Передавайте экспорт только нужному человеку: он содержит заметки и ссылки встреч и не зашифрован.

Повреждённые данные не перезаписываются автоматически: восстановите резервную копию или подтвердите сброс. Если браузер блокирует запись либо исчерпана квота, изменения остаются в памяти и показывается предупреждение — экспортируйте JSON до закрытия страницы. Очистка данных сайта удаляет локальную копию. Приложение не является резервным хранилищем.

Время встреч интерпретируется в выбранном IANA timezone независимо от пояса компьютера. Несуществующее или неоднозначное время перехода на летнее/зимнее время отклоняется. Общий прогресс считается по конечным темам; отметка родительского раздела не меняет дочерние статусы. Импорт ограничен 2 МБ, 300 встречами, 500 темами, 10 уровнями дерева и 50 проектами.

Терминал — **симуляция**, без shell, SSH, доступа к файлам компьютера и вызовов `eval`. Команды не исполняются в ОС. Нет Zoom API, напоминаний, авторизации и совместного редактирования.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run format:check
```

Браузерные проверки:

```sh
npx playwright install chromium
npm run test:e2e
```

Playwright сам запускает Vite на 5174, если сервер ещё не работает. Если установлен готовый Chromium, можно указать его вместо скачивания:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chrome-headless-shell npm run test:e2e
```

Unit-тесты проверяют валидацию импортов и URL, timezone/DST, прогресс дерева, восстановление хранилища и обработку команд. Браузерные сценарии проверяют CRUD, persistence, JSON, терминал, клавиатуру и ширины 1366/800/390 px. Снимки и traces находятся в игнорируемом `test-results/`.
