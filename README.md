# MiT-viis-2026

DevOps Mentorship Playground — закрытое пространство ментора и приглашённых менти.
Встречи, учебная программа, профиль и проекты, безопасный симулированный терминал.
Интерфейс на русском, адаптирован для ноутбука, телефона и Zoom рядом с браузером.

## Стек и требования

React 19, TypeScript, Vite, Tailwind CSS, Lucide, Zod, Luxon.
API: Node.js 24.13+, встроенный SQLite, серверные cookie-сессии. npm.
Один экземпляр API; HTTPS обязателен в production.

## Запуск

```sh
npm ci
npm run build
```

Создайте владельца, передав пароль через stdin (Bash):

```bash
read -r -s -p 'Пароль владельца (14+ символов): ' MIT_OWNER_PASSWORD
printf '\n'
printf '%s' "$MIT_OWNER_PASSWORD" | node server-dist/index.js create-owner your-login
unset MIT_OWNER_PASSWORD
npm run start:api
```

В другом терминале:

```sh
npm run dev
```

Откройте http://localhost:5174. У сервера по умолчанию APP_ORIGIN совпадает с этим
адресом; использование другого origin требует изменить конфигурацию. Если npm
нет в PATH, в подготовленном окружении доступен `./scripts/npm.sh`.

## Кто может менять данные

Анонимный посетитель видит вход. Владелец редактирует общие встречи, программу,
профиль, проекты, настройки, управляет аккаунтами и импортирует резервные копии.
Менти читает материалы и, если ментор разрешил, отмечает **свой** прогресс.
Права проверяются в API независимо от интерфейса. Публичной регистрации и
hardcoded-паролей нет. Подробности: [доступ и безопасность](docs/ACCESS_CONTROL.md).

## Настройка перед встречей

- «О менторе»: отредактируйте знакомство, технологии, ссылки и проекты.
- «Встречи»: задайте дату, время, часовой пояс, повестку и Zoom URL для Session 01.
- «Программа»: редактируйте дерево, описания и общий учебный ориентир.
- «Настройки»: создайте аккаунт менти и при необходимости включите личный прогресс.
- Данные-примеры находятся в `src/data/seed.ts`; не помещайте туда приватную информацию.

Терминал выполняет только локальные симуляции, не shell-команды.

## Данные и резервные копии

SQLite в `data/` содержит общие материалы, аккаунты, хеши паролей и сессий,
индивидуальный прогресс. Папка исключена из Git и Docker build context.
JSON экспорт/импорт в Настройках переносит **общие материалы**, а не аккаунты.
Для полноценной резервной копии используйте SQLite backup при эксплуатации API.
Старая LocalStorage-копия не является источником данных и не даёт прав. В Настройках
её можно скачать и затем импортировать владельцем. Автоматической миграции нет.

После изменений другого участника нажмите «Обновить». Одновременные правки общего
workspace защищены проверкой версии; конфликт нельзя молча перезаписать.

## Проверки и сборка

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run format:check
npx playwright install chromium
npm run test:e2e
```

`dist/` — статический клиент; `server-dist/` — API. Browser-тесты поднимают
изолированную тестовую SQLite БД и требуют свободный локальный порт 3001.
API-тесты проверяют роли, CSRF, cookie, блокировку аккаунтов и разделение прогресса.

## Развёртывание и ограничения

[Общая схема развёртывания](docs/DEPLOYMENT.md),
[архитектура](docs/ARCHITECTURE.md), [следующие шаги](docs/NEXT_STEPS.md).

Статический хостинг без API больше не предоставляет редактируемое пространство.
Конкретные VPS-пути, сети и конфигурация reverse proxy находятся только в приватном
инфраструктурном репозитории. Открытые исходники не содержат учётных данных.

MVP не включает MFA, email-восстановление, отдельные группы, live-совместную работу,
реальный SSH или управление серверами. Все вошедшие участники видят общие заметки
и ссылки встреч. Перед расширением аудитории добавьте OIDC/MFA и аудит действий.
